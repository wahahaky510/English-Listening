# Daily Listening

50組の英語・日本語例文で練習する、依存パッケージ不要の静的Webアプリです。

## 起動

Python 3を使い、このディレクトリで `python -m http.server 8000 --bind 0.0.0.0` を実行します。
スマートフォンへの配信にはHTTPS対応の静的ホスティングを使用してください。Service WorkerはHTTPSまたはlocalhostで動作します。

## 練習の順序

1. 英文非表示で英語2回
2. 英文表示でゆっくり英語1回（通常速度の70%）
3. 英文と日本語訳表示で日本語1回
4. 英文表示で英語2回

動画の実際の順序は、環境のYouTubeアクセス制限により未確認です。
端末のSpeech Synthesisを使います。音声一覧で「端末内」の声を選んでください。端末に英語・日本語音声がない場合はOSの設定から追加します。音質やオフライン音声の可否は端末依存です。アプリは初回取得後Service Workerで保存されます。音声自体のダウンロードはOS側で行います。

停止・再開は現在の例文の最初から。自動送り、速度調整、例文選択が可能です。最後に選んだ例文を端末に記憶します。バックグラウンド再生はブラウザにより制限される場合があります。

## 検証

`node --test tests/playback.test.cjs` で読み上げ順序と表示、速度、停止、次の例文への切替を確認します。音声APIを模擬したテストです。実際の端末での音声・オフライン再生は別途確認が必要です。

## OpenAIの事前生成音声

生成済みの音声と `audio-manifest.js` があると、その音声を優先再生します。未生成時は端末音声が動作します。OpenAI音声はAIが生成した音声です。

1. OpenAI APIの課金を設定し、音声生成に使用できるAPIキーを環境のシークレット `LISTENING_TTS_API_KEY` に安全に登録します。キーをチャットやファイル、GitHubコードに貼らないでください。
2. `node scripts/generate-audio.mjs --dry-run` で対象を確認します。
3. `node scripts/generate-audio.mjs` で先頭1例文の3音声を生成して聞き比べます。この処理からAPI料金が発生します。
4. 声に問題がなければ `node scripts/generate-audio.mjs --all` で50例文・150音声を生成します。同じ設定で生成済みのファイルは再利用します。
5. `audio/*.mp3` と `audio-manifest.js` をコミットして公開します。キーは公開されません。音声ファイルは一般公開されます。

モデルは `gpt-4o-mini-tts`。英語は `coral`、日本語は `shimmer` を使用し、日本語の自然なアクセント・抑揚・語尾を日本語の指示で指定します。OpenAIの声は多言語対応で、日本語専用の音声ではありません。ゆっくり版は発話の指示とAPIの速度設定（0.7倍）で別途生成します。アプリの速度調整は録音の再生速度を変更します。実際の自然さとゆっくり版の速度は音声を聞いて確認してください。

再生時は音声を全体取得してから再生します。Service Workerが一度取得した音声を保存し、後の再生に再利用します。すべての例文が初回からオフラインで利用できるわけではありません。ブラウザが保存データを消す場合もあります。

生成処理に依存パッケージは不要で、Node.js 24を使用します。通信先は `https://api.openai.com/v1/audio/speech` です。生成途中で失敗しても全件完了までマニフェストを切り替えません。

`node --test tests/playback.test.cjs` は録音再生・停止・取得失敗も含む6件を検証します。実APIによる生成、実際の音質、実機のオフライン再生は認証設定後に確認します。

## ランダム再生

「ランダムな順番で練習する」をオンにすると、既存50例文を重複なしで並べ替えます。「次の例文へ自動で進む」と組み合わせると、全例文を1周して停止します。全例文を終えて再び開始すると、新しい順に並べ替えます。停止・再開では現在の例文と順番を維持します。前・次ボタンもランダム順に沿って移動します。例文を直接選択すると、その例文の位置へ移動します。ランダムを切り替えると再生を停止します。各例文内の読み上げ順と日本語1.5倍は維持し、保存済み音声を再利用します。

## 教材切替

「教材」から「日常英語・初中級／50文」と「日常英語・中級／100文」を選べます。中級教材はユーザー提供の100組の英文・日本語訳を元に、余分な空白を整理し、メール処理の日本語訳を1箇所調整しました。元ページとの照合は未実施です。教材ごとに最後の例文を端末に保存します。教材切替時は再生を停止します。ランダム再生は選択した教材の全例文を重複なしで並べ替えます。

中級用音声の生成は `node scripts/generate-audio.mjs --course intermediate --all`、確認だけなら `--dry-run` を追加します。中級は100文×3種類で300音声です。生成済みの初中級音声は変更しません。出力は `audio/intermediate-*.mp3` と `intermediate-audio-manifest.js` です。初中級の生成は従来どおり `node scripts/generate-audio.mjs --all`。同時APIリクエストは最大3件（1文の各音声）に制限しています。

全検証は `node --test tests/*.test.cjs` で実行します。教材切替・音声参照・教材別の位置復元・中級100文のランダム再生も含みます。
